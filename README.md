# 两个人的账本

给情侣一起记账的小 App。记的是一起生活的每一笔，月底各自花了多少、谁先垫得多一些，App 会帮你们算清楚，但不会催、也不会说谁欠谁。

打开 👉 **https://couplecost.kittywu.fyi**

默认用日元，也可以换成人民币、美元、韩元、新台币、港币。

---

## 开始使用

1. **登录**：用 Google 账号登录。
2. **完善资料**：填昵称、选性别和自己的颜色（列表里你和 TA 用颜色区分）。
3. **建账本或加入账本**：
   - 先用的人「创建账本」，然后在首页点「邀请 TA 一起记账」，把邀请链接或 6 位邀请码发给 TA。
   - TA 打开邀请链接登录后，点「加入」就好。一个账本只能两个人。
4. **放到手机桌面**（推荐）：
   - iPhone：用 Safari 打开 → 分享 → 「添加到主屏幕」
   - 安卓：用 Chrome 打开 → 菜单 → 「安装应用」或「添加到主屏幕」

## 记一笔

点右下角的 **＋**：

- 选「支出 / 收入」和分类，用计算器键盘输入金额（可以直接算 `1200+380`）。
- 选 **个人** 或 **共同**：
  - **个人**：只算你自己的。
  - **共同**：两个人一起承担。拖滑条选「我 : TA」的比例（默认平摊），再选是谁付的钱。拉到两头就是「我请客」或「TA 请客」。
- 可以改日期、写备注。「保存再记」可以连续记好几笔。

点列表里的任意一笔可以看详情、编辑；长按可以快速删除。TA 的个人记录只能看，不能改。

## 共同账单：什么时候要对方确认

不想天天点确认，所以只有「让对方多出钱」的时候才要确认：

| 记成什么 | 要对方确认吗 |
| --- | --- |
| 我请客 | 不用，记了就算 |
| 按平时的比例 AA（账本设置里的默认比例） | 不用，记了就算，对方首页会提醒「TA 新记了 N 笔」，点「知道了」就清掉 |
| TA 请客、TA 比平时多出 | **要**，出现在对方首页的「待你确认」 |

- 改账单时，只有**金额、比例、付款人、个人 / 共同**变了才会重新判断、提醒对方；改分类、日期、备注不打扰对方。
- 要确认的账单：对方点「确认」或「有疑问」。**确认之前先全算付款人自己的**，不分摊、不进月末结算。
- 「有疑问」可以选原因（金额不对、不是共同的、比例不对……）、写一句话，还可以直接提议一个比例。不用确认的账单，觉得不对也可以点进去「有疑问」。
- 记账的人会看到「TA 对 N 笔有疑问」，可以「按 TA 说的改」（一键改好）、「回复 TA」或者自己编辑。

## 首页

- 上面三张卡片左右滑（或在折线图上快速一划）：**我们这个月花了 / 我这个月花了 / 我这个月收入**，折线图是最近 7 天。
- 左上角 **‹ 10月 ›** 可以看以前月份的账单。
- 右上角 📅 是收支日历，每天花了多少一目了然。
- 在最顶上往下拉可以刷新。

## 统计

- 按月 / 周 / 年 / 自定义时间看分类明细，「全体」或「只看我」。
- **月末结算明细**：这段时间谁请客几次、谁先垫付得多一些；差额不大时直接显示「基本扯平啦」。
- **共同消费清单**：每一笔共同支出两个人各承担多少。

## 我的

### 结清（像报销）

AA 的那份给了之后在这里记一下：

- **TA 该给我**：你先垫的、TA 那份还没给的。勾选（可以全选），点「已收到」。
- **我该给 TA**：TA 先垫的。给了钱之后请 TA 在 TA 那边勾「已收到」。
- **已结清**：结清过的记录，勾错了可以撤销。

只有先垫钱的人能点「已收到」。结清的照常算各自花了多少，只是不再进月末差额。

### 借款

大一点的钱借来借去，单独记在这里，不和每月开销混在一起：

- 点右上角 ＋：「我向 TA 借」或「我借给 TA」，可以选外币（默认账本货币）。记了就算。
- 点进一笔借款可以记还款（可以分几次还，或「剩下的全还了」）。**还款要对方确认**后才从「还剩」里扣掉。
- 两个人互相都借过钱时，下面会出现「相互抵消后，TA 还欠我 ¥X」，点「一键抵消」。
- 删除借款、删除已经确认的还款，都要先「申请删除」，**对方同意才会删**。

### 固定扣款

房租、话费、保险这类定期的支出，设置一次，到日子打开 App 时会自动记一笔：

- 周期可以选每月、每 2 个月、每季度、每半年、每年……
- 可以选首次扣款日：这个月已经交过的话，选下一次的日期就好。
- 共同的固定扣款，自动记下的账单按同样的规则：默认比例的只提醒对方，对方多出的要确认。
- 可以暂停、恢复、删除（已经记下的账单不会被删）。

### 账本设置

- **结算日**：每月从几号开始算一个周期（比如发工资那天）。
- **默认 AA 比例**、**记账货币**（只换显示单位，不做汇率换算）。
- **自定义分类**、金额颜色（支出绿 / 收入红，可以颠倒）。

## 隐私

- 两个人都能看到彼此的账单，包括 TA 的个人消费。
- 但统计数字只算「共同 + 自己的」，不会汇总告诉你 TA 一共赚了多少、个人花了多少。收入只算自己的。

## 常见问题

**App 提示「有新版本」？** 点「立即更新」。没提示但想更新，把 App 完全关掉再打开。

**数字是怎么算的？** 「我的 → 关于 → 结算算法说明」里有完整的说明和例子。

**有问题或想要新功能？** 「我的 → 关于 → 反馈 / 联系」。
